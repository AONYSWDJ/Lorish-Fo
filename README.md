# 作品集

## 概览  
本作品集对所有项目进行了系统性的总结与归纳。  
每个项目文件夹中均包含详细的文档说明与示例代码。  
您将在其中看到以下主要内容：

- **基于 Dash 的资产净值实时可视化系统：**  
  通过多线程技术实现数据的获取、存储与缓存，并支持对实时更新数据的动态展示。该系统以可交互曲线的形式实时呈现资产净值变化。

- **基于 LangChain 框架的智能 AI Agent（语言润色与邮件自动发送）：**  
  利用 LangChain 模块化能力构建的智能代理，可自动润色句式、优化表达结构，并实现自动化邮件发送。

- **订单流 CTA 期货趋势量化策略：**  
  基于订单流与市场深度数据的高频交易策略，结合异步协程以降低滑点并识别主力趋势，完成了 2023–2024 年期货市场的回测。

- **中证指数定期调整名单预测与报告：**  
  通过数据驱动的方法预测中证指数成份调整结果，并形成完整的分析报告与实现流程说明。

- **A股市场与新闻情绪关系研究（基于 Logistic、XGBoost 与 AI Agent）：**  
  利用机器学习模型与智能代理探讨市场情绪与股价波动之间的关联关系，构建了基于新闻文本情绪的分析框架。

- **成果展示与运行截图：**  
  包含各项目的运行结果与可视化展示，直观体现系统功能与策略表现。

> **说明：**  
> 本作品集仅用于展示作者在数据分析与量化策略开发方面的技术能力。  
> 所有策略与分析内容仅供学习与研究使用，作者不对任何实际应用结果承担责任。
